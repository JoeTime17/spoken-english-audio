# Spoken English Audio

Turn the user's draft into something they can comfortably say aloud. Produce a marked practice script, a clean speech-ready script, and two MP3s with the same US English male voice: a natural-speed version and a slower shadowing version.

## Rewrite the script

- Preserve the intended meaning, facts, numbers, uncertainty, and technical conclusions. Do not make a claim stronger merely to improve the wording.
- Prefer short sentences, familiar vocabulary, contractions, and natural transitions such as “Here’s why,” “The good news is,” and “So overall” when they fit.
- Keep useful domain terms, but make them pronounceable in the speech-ready copy. For example, render `LAST_K` as “Last K,” `GroupBy` as “Group By,” and symbols or dense numbers in spoken form when the TTS engine could misread them.
- Match the user's English level. Make the script easy to deliver without making it childish or unnaturally slow.
- Create natural pauses in the clean script with punctuation, sentence boundaries, and paragraph breaks.
- Save the clean speech-ready text as `<input-stem>_spoken.txt` unless the user gives another destination.

## Annotate the practice script

Create `<input-stem>_marked.md` from the final clean script. Keep its wording identical; add only capitalization and these speaking markers:

- `/` — a short pause between thought groups
- `//` — a longer pause or a completed sentence
- `UPPERCASE` — the main stressed word or phrase; mark selectively rather than capitalizing every content word
- `↗` — a slight rise for an unfinished thought, setup, or contrast that continues
- `↘` — a fall for a completed statement, conclusion, or confident key point

Group words by meaning rather than fixed length. Avoid pausing between a modifier and the word it modifies, between a verb and a short object, or anywhere that breaks the intended meaning. Do not make every phrase rise, and do not over-mark secondary stress.

The marked file is for human practice only. Never send `/`, `//`, arrows, headings, legends, `[pause]`, or `[[slnc ...]]` to the speech engine. Generate audio only from the clean `_spoken.txt` file.

Show the revised script to the user when review is requested. If the user only asks for audio from already-approved wording, preserve that wording except for pronunciation-safe rendering.

## Generate the audio

Use [scripts/generate_mp3.py](scripts/generate_mp3.py). Its defaults are:

- Voice: `en-US-BrianMultilingualNeural` (approachable US male voice)
- Natural version: `-4%` speaking rate
- Slow shadowing version: `-15%` speaking rate
- Pitch: `-2Hz`
- Outputs: `<base>_normal.mp3` and `<base>_slow.mp3`

The script requires the `edge-tts` Python package and sends the complete speech text to Microsoft's online neural speech service. Before sending, inspect the text for secrets, credentials, or sensitive personal information. If it contains sensitive material, tell the user and obtain explicit approval or use a user-approved local alternative. Never describe generated audio as a recording by a real person or as a cloned voice.

If `edge-tts` is unavailable, create a task-specific virtual environment in a temporary directory and install it there. Network access or package installation may require user approval. Do not add the dependency to the user's project unless they request that.

Example:

```bash
python3 -m venv /private/tmp/spoken-english-audio-venv
/private/tmp/spoken-english-audio-venv/bin/pip install edge-tts
/private/tmp/spoken-english-audio-venv/bin/python scripts/generate_mp3.py \
  path/to/script_spoken.txt --force
```

Use `--voice`, `--normal-rate`, or `--slow-rate` only when the user asks for a different accent, voice, or pace. Use `--force` only for files generated by the same workflow or when the user asked to replace them.

## Verify and deliver

- Confirm that both MP3s exist, are non-empty, and have plausible durations; use `ffprobe` when available.
- Give the user clickable links to the marked practice script, clean speech-ready text, normal version, and slow version.
- Briefly identify the normal version as the natural-delivery model and the slow version as the shadowing aid.
